## About the site
This website is my personal portfolio showcasing my background, my completed projects from the course, and a contact section. The site is built using semantic HTML5 and styled with Tailwind CSS to ensure a modern and clean user interface.

## Design Decisions
1. **Responsive Layout:** CSS Grid and Flexbox were utilized to ensure the layout adapts smoothly from mobile screens (375px) to desktop viewports (1200px), with the project cards collapsing into a single column on smaller screens.
2. **Color System:** CSS variables were implemented to seamlessly switch between light and dark themes across the entire page without breaking the visual hierarchy.
3. **Interactive Validation:** The contact form uses custom JavaScript validation instead of browser default tooltips to provide clear, specific error messages for empty fields and malformed email formats.
